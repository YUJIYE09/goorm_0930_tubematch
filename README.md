# 튜브매치 연습용 데모

서비스 기획서(05)와 UI 목업을 바탕으로, 바이브 코딩 입문자가 따라 만들 수 있는 수준으로 줄인 앱 데모입니다.
빌드 도구나 서버 없이 HTML·CSS·자바스크립트 파일만으로 돌아갑니다.

## 실행 방법
1. 이 폴더(`demo/`)를 통째로 내려받습니다.
2. `index.html`을 더블클릭해 크롬 같은 브라우저로 엽니다. 끝.

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 (왼쪽 메뉴, 오른쪽 화면 자리, 상세 창) |
| `style.css` | 색·글꼴·배치. 색은 맨 위 변수로 한 번에 바꿀 수 있음 |
| `data.js` | 가상의 채널 8개, 섭외·캠페인 예시 데이터 |
| `api.js` | 유튜브에서 채널 정보를 가져오는 곳. 지금은 가짜 데이터를 돌려줌 |
| `app.js` | 화면 그리기와 버튼 처리 |

## 들어 있는 기능 (기획서 기능 ID)
- **채널 탐색 (F1)**: 이름 검색, 카테고리·구독자 구간 필터, 그룹에 담기
- **채널 URL로 추가 (F2)**: `@핸들`이나 채널 주소를 넣으면 채널을 추가
- **채널 리포트 (F3, F5)**: 공식 지표와 자체 지표를 색으로 구분, 최근 영상, 협찬 배지, 섭외 상태 버튼, 팀 메모
- **섭외 보드 (F4, F5)**: 후보 → 연락함 → 협의 중 → 확정 / 거절 칸반, CSV 만들기
- **캠페인 (F6)**: 협찬 영상 등록, 조회수·좋아요·댓글 합계, 조회당 비용

데이터는 브라우저(localStorage)에 저장돼 새로고침해도 남습니다. 왼쪽 아래 "데이터 초기화"로 되돌립니다.

## 진짜 유튜브 데이터 연결하기
1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만듭니다.
2. "YouTube Data API v3"를 사용 설정하고 API 키를 발급받습니다.
3. `api.js` 맨 위 `YOUTUBE_API_KEY = ""` 따옴표 안에 키를 붙여 넣습니다.
4. 채널 탐색 화면 아래 "채널 URL로 추가"에 `@채널핸들`을 넣어 봅니다. `channels.list`를 불러 진짜 구독자·조회수가 나옵니다(호출 1번에 쿼터 1 유닛).

API 키가 들어간 파일은 깃허브 등에 공개로 올리지 마세요.

## 다음 연습 과제
1. **최근 업로드일 가져오기**: `channels.list` 결과의 업로드 재생목록 ID로 `playlistItems.list`를 불러 최근 영상 날짜를 채워 보기
2. **캠페인 조회수 진짜로**: 협찬 영상 등록 칸에 영상 URL을 받아 `videos.list`로 조회수·좋아요·댓글 가져오기
3. **그룹 여러 개 만들기**: 지금은 그룹이 하나뿐. `state.pipeline`을 그룹별로 나눠 보기
4. **CSV 파일로 저장**: 지금은 콘솔에 출력만 함. `Blob`으로 파일 내려받기 만들기

## 원본 기획과 다른 점 (단순화한 부분)
- 로그인·팀원·결제, 관리자 콘솔 없음
- 그룹은 하나("가을 수분크림 런칭")로 고정
- 30일 보관 규정은 안내 문구로만 표시 (실제 삭제 로직 없음)
- 자체 지표는 "구독자 대비 조회율" 하나만 예시로 계산
